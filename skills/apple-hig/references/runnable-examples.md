# Runnable examples

The companion repository contains a browser gallery with a concrete task for every one of the 173 indexed topics, ten motion experiments, and pictures captured from actual renderers.

[Gallery instructions](https://github.com/fareslaggoun7/apple-hig-skill/blob/main/examples/gallery/README.md) · [Complete topic index](https://github.com/fareslaggoun7/apple-hig-skill/blob/main/examples/gallery/TOPICS.md) · [Motion previews](https://github.com/fareslaggoun7/apple-hig-skill/blob/main/examples/gallery/MOTION.md)

When using an example, identify its topic, intended action, Apple source, platform context, and scope. The gallery displays the dated source-card interpretation beside the runnable task. Read the applicable cards and current official sections before carrying a behavior into a production interface.

The controls use real browser interactions. Device, account, payment, and SDK examples explicitly simulate their underlying integration; no actual transaction, authentication, sensor, invitation, or Apple service is invoked. Browser visuals, durations, easing, and spring constants are original educational choices, not Apple specifications. Prefer platform-native controls for native applications.

Use the sheet and dialog routes to inspect cancellation and focus recovery; loading for failure and retry; search for no-result recovery; drag/reorder for keyboard alternatives; and motion for interruptible transitions and reduced alternatives. Screenshots and GIFs show appearance, not assistive-technology correctness. Test the actual target runtime separately.

The portable skill ZIP retains the source cards and this routing guide. The larger gallery is distributed separately, so Claude.ai ZIP uploads, Claude Code, and Codex keep their existing installation structure.
