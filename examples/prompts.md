# Prompt library

Replace the interface description with your actual screens, code, or product context. These prompts are task starters, not benchmark results.

## 1. Review an iPad editor

```text
Use the apple-hig skill to review this iPad document editor.
People resize the window and use touch, a keyboard, and a trackpad.
Check navigation, focus, text expansion, and recovery from save errors.
Cite source sections for consequential recommendations and list untested states.
```

## 2. Implement a Mac toolbar change

```text
Use the apple-hig skill to add the requested toolbar action to this macOS app.
Inspect the existing command structure and customization behavior first.
Complete the change, cite applicable guidance, and test affected command paths.
```

## 3. Inspect a task sheet

```text
Use the apple-hig skill to review this sheet's completion and dismissal paths.
Distinguish saving, cancelling, and returning to a previous step.
Ground findings in the actual implementation and current source sections.
```

## 4. Adapt for the web

```text
Use the apple-hig skill for a HIG-based web adaptation of this small editor.
Use semantic HTML, keyboard interaction, visible focus, and responsive layout.
Identify which decisions are web adaptations and avoid claiming native fidelity.
```

## 5. Resolve an exact-measurement question

```text
Use the apple-hig skill to investigate control sizes for this iOS game.
Read current prose and tables, retain units and context, and flag conflicts.
Do not invent a universal size or claim a numerical accuracy guarantee.
```

## 6. Plan a spatial interface

```text
Use the apple-hig skill to plan this visionOS browsing experience.
Consider input methods, spatial layout, accessibility, and comfort.
Separate sourced recommendations from your proposals and runtime assumptions.
```
